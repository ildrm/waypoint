Owner: R27. Reviewers: R01, R18, R23, R26, R29. Status: proposed documentation, 2026-10-29; no human approval.

| Gate | Required production evidence | Current state |
|---|---|---|
| Product/scope | R01 accepted operating model/catalog/constraints | Proposed; owner decisions open |
|14 languages | Source/variants, qualified reviews, current critical copy, font/report QA | Language identities confirmed; reviews pending |

| Workflows/rules | Engine acceptance, unknown/back-edit/conflict/idempotency proof | Documented fixtures and full schema checks; engine behavior untested |
| Security/privacy | Scoped auth/revocation tests, ASVS mapping, policy/legal review | Proposed design only |
| Accessibility/UX | Full journey manual+automated evidence, rendered native-language QA | Static previews rendered/inspected; interactive/browser/native-language evidence pending |
| Reliability | Representative load, alert/backup/restore drills and support owners | Targets/runbooks only |
| Free use | No platform billing/payment/paywall | Owner-confirmed requirement; implementation absent |
| Handover | Named owners, runbooks, training, rollback and unresolved risk acceptance | Documentation prepared; human acceptance pending |

Documentation can be complete as a proposed design while production readiness is blocked by these evidence gates. Never mark stakeholder, security, linguistic or accessibility approval without actual authority/evidence.
