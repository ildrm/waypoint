# accessibility practice profile

Owner: R13. Reviewers: R31, R34. Status: incorporated-as-documentation-profile; revision1, 2026-10-29.
Related capability families: 10. Sources/assumptions: authorized brief and [reference register](../standards-and-references.md). Open decisions: [owner register](../assumptions-and-open-questions.md).

Purpose: provide reusable methods for the named capability families under the documentation-only boundary.

Owner roles: R13.

Inputs: Screens, component states, content.

Method: Map WCAG 2.2 AA criteria to semantics, keyboard/focus, error assistance, zoom/reflow and target size; define later assistive technology tasks.

Outputs: Accessibility matrix and visual QA plan.

Relevant standards/practices: Loaded accessibility2.0; WCAG 2.2, WAI-ARIA APG.

Review checklist: Native controls, focus not obscured, labels, contrast and non-drag alternatives specified.

Limitations: Static artifacts cannot prove WCAG conformance. This is a domain practice reference, not a native skill installation or specialist approval.
