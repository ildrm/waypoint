# Glossary

Owner: R14. Reviewers: R02, R15. Status: proposed specification, 2026-10-29; no human approval.
Sources: [authorized brief](sources/documentation-super-mega-prompt.md), [inventory](source-inventory.md). Related IDs: OUT-SCOPE, OUT-PRICE, OUT-TEAM. Open decisions: [decision log](assumptions-and-open-questions.md). Practice: [content-localization](skills/content-localization.md).

| Term | Product meaning |
|---|---|
| Flow | Independently released stages/questions/rules/outputs on a shared engine |
| Stage | Logical group; does not force a fixed number of questions |
| Answer | State plus typed canonical value, provenance and revision |
| Unknown | Applicable but not known; distinct from zero/no/unanswered |
| Inactive | Hidden due to upstream applicability; excluded from derivation/pricing |
| Fact | Normalized answer-derived value with source and scope |
| Rule | Restricted deterministic condition/effect in navigation, classification, recommendation or pricing category |
| Business release | Manifest pinning content, rules, schema, parameters and translation versions |
| Estimate | Revisioned preliminary effort, price, duration and team proposal; not a quotation/contract/invoice |
| Price book | Effective, currency/market-specific approved commercial configuration |
| Cost | Internal expenditure; separate from customer selling price |
| Contingency | Disclosed allowance for scoped uncertainty; not margin |
| Margin | (Selling price minus cost)/selling price; not markup |
| FTE | Assigned hours divided by defined full-time hours for the period |
| Unique headcount | Distinct people, integer; may combine compatible roles |
| Peak concurrency | Maximum simultaneous active contributors, separately reported |
| RTO | Maximum planned recovery time after outage; target, not guarantee |
| RPO | Maximum acceptable lost data window before incident |
| Proficiency | User's demonstrated skill, distinct from project complexity or package tier |
| Tier | Commercial package classification; cannot imply proficiency |
| Locale | BCP47 language/region/script formatting context; not currency or jurisdiction |
| Self-reported evidence | User account of observations; neither externally verified nor a probability of success |
| Hypothetical | Invented example input, workload or rate with no market validity |
| Review perspective | Role-based assessment; human and agent reviews distinguished explicitly |
