| US-07 | Act on evidence | Given once-only purchases, when reviewing retention, then do not infer failed repeat purchasing | AC-13 |
| US-08 | Preserve old price | Given updated catalog, when opening old estimate, then old snapshot remains and explicit refresh creates revision | AC-03,04 |
| US-09 | Publish safely | Given invalid rule/price/translation, when publishing, then block atomic release with repair details | AC-08 |
| US-10 | Protect ownership | Given foreign run ID, when reading/exporting, then deny without answer leakage | AC-07 |
| US-11 | Use for free | Given any supported flow, when completing and exporting, then no checkout or payment is requested | AC-16 |
