# Admin resource specifications

Owner: R18. Reviewers: R05, R23, R27. Status: proposed documentation, 2026-10-29; no human approval.
Sources: [authorized brief](../00-governance/sources/documentation-super-mega-prompt.md) and user clarification (14 named languages; free use; no platform payments). Related IDs: FR-18–24, AC-08. Open decisions: [register](../00-governance/assumptions-and-open-questions.md). Practice: [architecture-data-api](../00-governance/skills/architecture-data-api.md).

All mutations require expected revision and server-side capability checks. Fields below are mandatory design minimums; labels/options are translated separately. Forms display draft/released state and user impact before save.

| Resource | Fields | Validation | Permissions | Filters | Bulk actions | States | Dependencies/version behavior | User impact |
|---|---|---|---|---|---|---|---|
| Flows | id, key, name, purpose, stages, output config | Unique stable key; at least one terminal path | content_author/reviewer/publisher | status, domain, release | clone, validate; never bulk publish bypass | draft/review/published/retired | Question/rule/library refs must resolve; new manifest | New starts only on published flow |
| Stages/questions/options | stable IDs, order, type, schema, help, translation keys, applicability | Bounded enum; no overlapping options; unknown policy; no ID reuse | content_author | flow, stage, type, stale | move via controls, clone, deprecate | draft/released/deprecated | Dependency closure and translation hashes; immutable release | Relevant screens and hidden-answer invalidation |
| Shared libraries | library ID, version, question/rule refs, consumers | Pinned references; compatible schema; no circular refs | library_author/reviewer | consumer, version | impact preview, clone | draft/released/retired | Upgrades explicit per flow, never floating latest | Consistent reused content |
| Rules | ID, category, typed predicates, effects, priority | Allowed operators; DAG; exclusive conflict checks | rule_author/reviewer | category, flow, unused | simulate, validate, disable draft | draft/valid/conflicting/released | Question/option/parameter/output references; new release | Navigation, scope, classification, price explanations |
| Catalog/features/levels | ITEM ID, deliverables, quantities, prerequisites, exclusions, level dimensions | Distinct skill/complexity/tier; eligibility defined | catalog_editor/domain reviewer | domain, eligibility, status | clone, retire, validate | draft/approved/published | WBS/price/template refs current | Match/no-match and included scope |
| Price books/rates | currency, market, effective interval, role/item/unit amounts, adjustments | Exact decimals; no overlaps/missing roles/double inclusion | price_editor/commercial_approver | currency, market, effective, flow | import preview, simulate, retire | draft/approved/scheduled/effective | Snapshot at calculation; history immutable | Informational customer-project price only |
| Parameters/overrides | PARAM ID, type, unit, domain, shared value, allow_override, flow value | No coercion; allowed scope; no cycles | settings_editor/publisher | scope, consumer, override | impact preview, validate | draft/released | Effective value/source; successor manifests | Changed business behavior only new runs |
| Translations | key, locale, text, source hash, placeholders, criticality, reviewer | ICU/placeholder parity; qualified review/current hash | translator/language_reviewer | locale, flow, stale, coverage | export/import staged, assign | draft/review/approved/stale/published | Source edit invalidates approval;14-language gate | Meaning, direction and report coverage |
| Report templates | template/version, allowed variables, locale, layout/assets | No arbitrary code/includes; escape outputs; licensed assets | template_author/reviewer | locale, format, version | preview fixtures, clone | draft/approved/published | Fact/output refs and font support; render snapshot | Accessible sourced report/export |
| Releases | manifest versions, draft hash, review evidence, activation/retirement | Atomic valid refs; exact approved diff; compatible rollback | publisher | flow, status, date | validate, compare; no destructive mass activation | review/approved/scheduled/published/retired | Pinned versions; old runs preserved | New-run behavior and locale availability |
| Staff/roles | invitation, scopes, role, MFA status, expiry | Least privilege; no silent self-escalation | security_admin | role, expired, revoked | revoke scoped invitations/sessions | invited/active/suspended/revoked | Live policy, not pinned config | Current access everywhere |
| Runs/reports/jobs | opaque ID, owner, version, status, diagnostic code | Scoped read; staff cannot overwrite answers | support/privacy roles | flow, status, error, age | retry authorized failed export, not mass answer edit | active/paused/completed/failed/deleted | Ownership and retention; idempotent jobs | Safe recovery without history mutation |
| Simulator | fixture IDs, input context, expected/actual trace | Fictitious data; bounded inputs; no production writes | author/reviewer | flow, case, result | run fixture set, export trace | draft/passed/failed | All rule/price/locale refs versioned | Pre-publication evidence only |
| Analytics/audit | event definitions, redacted dimensions, retention | No raw answers/tokens; small-cell suppression | analyst/auditor | flow, locale, time, outcome | export scoped aggregates | collected/redacted/expired | Privacy purpose/current permissions | Service improvement and accountable changes |
| Imports/privacy requests | schema version, mapping, checksum, requester, purpose, status | Size/type/schema; identity check; row errors; no partial unsafe publish | import_operator/privacy_operator | status, type, policy, due | dry run, approve mapping, retry | received/validated/queued/failed/fulfilled | Retention/backup/export dependencies and audit | Portable configuration/data and deletion transparency |

Bulk mutation stages exact target IDs, dry-run errors, diff and approval; successful rows do not silently publish when others fail. Deleted referenced IDs are deprecated, not erased. Internal cost/rate fields are restricted from public/support views. No payment processor, billing or paid entitlement resource exists.
