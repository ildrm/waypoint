| Phase | Included behavior | Exit gate |
|---|---|---|
| Discovery/design validation | Owner decisions, domain catalog, rates, locale/source choices, integration feasibility, usability review | Accepted scope and evidence; no claimed production completion |
| Core configuration | Release manifests, typed defaults, stable IDs, permissions, rule dry runs | Reproducibility/ownership/publication acceptance |
| Public workflows | Startup/software/matching, save/resume/review, scenarios/results | Positive/negative paths and uncertainty handling |
| Commercial/localization | Catalog/overrides, exact arithmetic,14-language content and reports | Rate authority, language reviewer coverage, history preserved |
| Reliability/handover | Observability, restore drills, privacy operations, staff training | Readiness checklist with owner evidence |

Lean scope may defer optional AI, native platform apps, scheduled external webhooks and advanced analytics, while preserving exact14-language production requirement and accessibility/security invariants. Balanced adds richer catalogs and scenarios. Accelerated changes resourcing only for independent work; it cannot bypass review, translation, procurement or critical dependencies. See delivery estimates for provisional capacity and range.

A change request names need, questions/rules, data/API, translation, pricing/WBS, schedule, risks and acceptance effects. R01 decides scope, R29 commercial rules and R24 policy; R31 records decision. Unchanged historical runs remain pinned.
