# User journeys

Owner: R08. Reviewers: R07, R14. Status: proposed specification, 2026-10-29; no human approval.
Sources: [brief](../00-governance/sources/documentation-super-mega-prompt.md), [source inventory](../00-governance/source-inventory.md). Assumptions/open decisions: [DEC-01–10](../00-governance/assumptions-and-open-questions.md). Related IDs: WF-SESSION, WF-STARTUP, WF-SOFTWARE, WF-MATCH, WF-RESULT. Practice: [experience-research](../00-governance/skills/experience-research.md).

| Journey | Before | Steps | Outcome/recovery |
|---|---|---|---|
| Founder | Has uncertain opportunity | Choose startup; define venture context; answer evidence questions; clarify conflict; review actions | Prioritized report with blocker/evidence caveats; unknown produces experiment rather than score |
| Software sponsor | Has rough scope | Choose software; goals/surfaces/domain details; quantify demand; confirm features; compare scenarios | Preliminary architecture/WBS/price/schedule/team; missing rate shows incomplete price |
| Service seeker | Needs help or level | Define need, prerequisites, constraints and evidence; inspect eligible catalog alternatives | Explained match/no-match; cannot buy a higher tier to imply higher skill |
| Returning user | Has saved run | Authenticate or prove anonymous resume token; select revision; see released version and expiry; edit | Dependency invalidation preview and revised result; old result preserved |
| Content staff | Needs change | Clone draft; edit; inspect affected facts/translations/prices; simulate; request review; publish | Atomic release; failed checks leave prior release serving |

Each journey must show help at a consistent location, save status, an uncertainty route and an accessible back action. Resume failure offers safe account recovery without exposing whether another person's project exists. Locale switching preserves canonical answers but requires explanation if current release lacks target critical copy.
