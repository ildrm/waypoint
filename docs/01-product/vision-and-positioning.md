# Vision and positioning

Owner: R01. Reviewers: R02, R03, R04. Status: proposed specification, 2026-10-29; no human approval.
Sources: [brief](../00-governance/sources/documentation-super-mega-prompt.md), [source inventory](../00-governance/source-inventory.md). Assumptions/open decisions: [DEC-01–10](../00-governance/assumptions-and-open-questions.md). Related IDs: NEED-01–08. Practice: [product-requirements](../00-governance/skills/product-requirements.md).

Help people decide the next useful step with visible reasoning. A founder receives prioritized evidence-building actions; a software purchaser receives a scope/architecture/estimate with assumptions; an adviser sees why a catalog service fits. Users can revise answers without losing the reasoning behind previous results.

| Need | Job and desired outcome |
|---|---|
| NEED-01 | Founder identifies the most consequential next experiment without a false probability-of-success score |
| NEED-02 | Purchaser describes software precisely enough to compare viable solutions and phased scope |
| NEED-03 | Purchaser sees separate effort, price, duration, staffing and recurring costs |
| NEED-04 | User completes/resumes/reviews in the chosen supported language and direction |
| NEED-05 | Operator changes content/rules/prices/settings safely with preview and permission boundaries |
| NEED-06 | User/adviser can reproduce and explain an old result after catalog updates |
| NEED-07 | Operator protects data and recovers service without silent unauthorized edits |
| NEED-08 | User receives an honest no-match/partial/manual-review outcome when evidence is insufficient |

Differentiation is inspectable reasoning and scenario comparison, not guaranteed success or instant definitive engineering. Alternatives include a consultant interview, generic forms, commercial calculators and hosted product selectors. This product combines structured elicitation with an explicit review boundary. It should recommend standard products when they fit rather than biasing toward costly custom development.
