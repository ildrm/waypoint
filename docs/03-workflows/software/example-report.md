# Example software discovery report

Owner: R04. Reviewer: R02, R27. Status: proposed specification; no human approval.
Sources: supplied documentation prompt; startup source where stated. Related IDs: WF-SOFTWARE; OUT-ARCH; OUT-PRICE.
Open decisions: production locales, markets/currency, organization model; see [owner decisions](../../00-governance/assumptions-and-open-questions.md) from flow documents.
Practice profiles: [workflow and assessment](../../00-governance/skill-registry.md) (relative to flow folders; shared documents use ../00-governance/skill-registry.md).

Fictitious preliminary report: River Library. This narrative demonstrates output format; the fully populated case/price calculations are owned by [customer examples](../../16-examples/).

**Confirmed hypothetical scope:** Q-SW-SURFACES=[web]; Q-SW-WEB-KINDS=[content]; content editors need draft/review/publish, 24 pages at launch and 100 at 12 months. Q-SW-CONCURRENCY reports 20 active people in busiest five minutes, Q-SW-REQUESTS forecasts 2 typical/8 peak requests per second, mostly public reads. No registered-customer journey, payments or native device requirement. No inference from registered account count is used.

**Proposed scope and architecture:** compare a standard CMS with a custom SSR application. A CMS is the preliminary fit if the editorial/ownership/license constraints can be demonstrated in a proof of fit. Reject a mobile app because none was requested; independent services have no demonstrated need. Keep content production, redirects, search, accessible templates, monitoring and editor handover visible.

**Commercial and delivery status:** WBS, rate snapshots, resource schedule and exact amounts must be read from the complete case. This format sample intentionally does not invent live rates. If the administered catalog lacks a required rate, OUT-PRICE is incomplete and total is null.

**Uncertainty and next action:** content readiness, actual locale list and hosting geography need confirmation. The next deliverable is an editorial/content inventory and approved feature matrix. This is an estimate workflow, not an offer, contract or purchase.
