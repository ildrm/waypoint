# Startup derivation method

Sources: [authorized brief](../../00-governance/sources/documentation-super-mega-prompt.md) and user clarification (14 named languages; free use; no platform payments). Each canonical selection yields a scoped evidence fact, retaining question ID, answer revision, period and source. Decision tables map each question to a next work item. No ordinal score is inferred from option letters.

First resolve known prerequisite/feasibility/cash blockers. Then select the earliest unvalidated decision dependency: customer/problem -> usable outcome -> delivered demand/normal price -> unit economics/acquisition -> controlled growth. This is a proposed prioritization method, not a validated universal venture model. A later-stage self-description cannot override absent underlying evidence.

For weak or unknown evidence, propose an experiment with named hypothesis, method, measure, decision rule, owner and review date; user sets context-specific numeric targets before running it. For strong self-reported evidence, preserve strength and limitations and ask whether it replicates.15-stage report covers people, operating requirements, offering, acquisition, cash, retention, funding, capacity, dependencies and learning. Return rates require eligible denominator and natural interval. One-time purchases can use referrals, outcomes or adjacent need; never penalize natural non-repeat purchases.
