1. Sign in with assigned role/MFA; confirm environment and admin locale.
2. Choose content flow and edited-content locale; inspect published version before cloning draft.
3. Edit stable fields, schemas, rules or translations; inspect effective settings and dependency impact.
4. Run simulator including unknown, back-edit, price and locale cases; repair entity-level errors.
5. Request appropriate language/domain/commercial review of exact draft.
6. Publisher activates approved manifest; inspect diff and verification record.
7. Retire or roll back using release controls; do not edit historical rows.

For pricing change use estimate catalog, not platform billing. Missing rate means incomplete customer-project price. For translation source edits expect stale review and block critical-copy publication. If permission denied ask authorized administrator through product process; never bypass via bulk import. Failed save conflicts require reload/diff and deliberate merge.
