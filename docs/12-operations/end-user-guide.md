Choose language and assessment purpose. Use one project/venture per run; describe current facts and planning horizon. Select all compatible features where marked; use “I do not know” when evidence is missing. Numeric questions explain units/time window. Save status distinguishes saved, pending and unsaved; keep resume credentials private.

Back edits may remove now-irrelevant answers from the new scope. Review feature matrix, assumptions and conflicts before generating. Reports explain why each recommendation follows and what evidence would refine it. Prices are preliminary estimates for the project being assessed, not charges for using this platform. Assessment and export are free; no payment is requested.

Compare alternatives by explicit changes. Old reports retain original prices; refresh creates a labeled new estimate. Unknown integration/rate or unresolved constraints may yield partial/manual review. If export fails use structured report and retry; if access fails follow safe recovery. Language switch preserves canonical facts; missing approved copy is explained. Request scoped data export/correction/deletion through support; retention/policy limits shown.
